# FightProTaekwondo

Website storefront modern, sport, dan minimalis untuk brand **FightProTaekwondo**.

## Isi project
- `index.html` — struktur landing page / storefront.
- `style.css` — desain responsive dengan brand color merah, biru, putih, hitam.
- `script.js` — slider, search, filter, wishlist, cart, modal detail produk, tracking demo, dan WhatsApp checkout.

## Fitur
- Hero section + CTA.
- Slider otomatis 6 featured gear.
- Kategori produk.
- Best seller product grid.
- Search + filter harga, ukuran, warna, dan merek.
- Wishlist dengan localStorage.
- Keranjang dengan quantity + total.
- Checkout langsung ke WhatsApp.
- Template WhatsApp: `halo permisi kak, mau pesan alat yang..`
- Promo / discount.
- Panduan ukuran.
- Testimoni.
- Artikel / blog.
- Tracking pesanan demo.
- Toggle ID / EN.
- Responsive desktop / tablet / mobile.

## Cara menjalankan
1. Extract ZIP.
2. Buka `index.html` di browser.
3. Tidak membutuhkan backend untuk demo.
4. Karena gambar di-hotlink, koneksi internet diperlukan agar foto tampil.

## Kustomisasi cepat
- Produk: edit array `products` di `script.js`.
- Warna: edit variabel `--red`, `--blue`, `--black` di `style.css`.
- Nomor WhatsApp: cari `6285814568534` di `script.js` dan `index.html`.
- Konten brand / harga / ukuran: edit `index.html` dan `script.js`.

## Catatan
Ini adalah **frontend demo/e-commerce mockup**. Checkout, tracking, payment, stok, dan order belum terhubung ke database/backend.
